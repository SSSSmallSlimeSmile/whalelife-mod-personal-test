# WhaleLife 本地改动（未完成 / 需要动主干）

这个库放三类东西：

1. **还没完全验通的插件**——能独立加载，但装到别人机器上有已知风险
2. **需要动主干的补丁**——不是插件能解决的部分，只能改 `core/`
3. **改动说明文档**——每份都写现象、原因、修法、验证

成品插件在另一个库：[`whalelife-mod-personal`](https://github.com/SSSSmallSlimeSmile/whalelife-mod-personal)

**不是 WhaleLife 官方项目。** 上游是 [`iinukami/whalelife`](https://github.com/iinukami/whalelife)，AGPL-3.0 加附加条款，原文在 `上游许可/`。

---

## 先说清楚：验证范围

这个库里的补丁和文档，**只在本人那台 Windows 电脑上跑过**。没有在手机上跑过，也没有在第二台电脑上跑过。

补丁尤其要小心——基线绑死，换台机器、换个版本就可能全废。看到“能用”，意思是“在我这台机器上能用”，不是“在哪都能用”。

### `voice` 嗓子

**来源：本机自建。** 搬进 WhaleLife 时从 AstrBot 那边的语音能力并过来的，**没有对应的上游仓库**——作者公开的 8 个仓库里没有 voice，主仓库的 `plugins/` 也只有一份 `AGENTS.md`。GPT-SoVITS 服务、参考音频、参数这些出自我们自己的环境。

因此这份代码没有“上游原版 diff”可附，下面列的改动是相对这份代码最初搬进来时的样子说的。将来若发现某部分确实来自别处，按那边的许可补声明。

（本段之前写的是「基础版本由上游提供」，那是错的，2026-11-18 更正。）

主要改动：

| 位置 | 改动 |
|---|---|
| `ui.ts` | 新增文件，嗓子配置页：状态条、启动/停止/刷新、两个伴随开关、服务参数表 |
| `index.ts` | 新增 `ctx.web.page("/plugins/voice/")` 与四个 api：`status` / `start` / `stop` / `save` |
| `index.ts` | 修 `pidByPort()` 取列错位。`netstat -ano` 的列是 `0=协议 1=本地地址 2=对端地址 3=状态 4=PID`，原代码用 `cols[1]` 判 `LISTENING`、`cols[2]` 取地址，永远匹配不到，返回空数组 |
| `index.ts` | 修页面「刷新状态」无可见反馈 |
| `index.ts` | `DEFAULTS` 里四处本机绝对路径清空，改由 `data/config.json` 提供 |
| `plugin.yaml` | 名称改「嗓子」，版本升 0.2.0 |

第一个 bug 的表现：状态显示在跑、点停止说没进程、点启动又说已在跑。四个现象同一个原因。

默认值里的本机路径已清空，真实值只在 `data/config.json`（不进库）。

| 文件 | 内容 | 基线 |
|---|---|---|
| `all-20261118c.patch` | 全部改动，160,797 字节，31 文件 | `2ee7b09` |

`all` 就是两份包首尾拼接，应用一份即可。三份都在 `2ee7b09` 干净树上 `git apply --check` 通过。

**注意**：补丁截止 2026-11-18 03:30，含把密钥挪进环境变量的 ENV 引用、聊天页念话按钮、账本插件化、插件页若干修复，以及 `core/llm.ts` 允许单次调用覆盖参数（供识图关掉思考）。不含 10 个一次性调试脚本（`tools/kan-edit-*`、`scripts/*-20261115.mjs` 等），它们仍在本地仓库里，但没打进补丁，作者那边不需要。

补丁只收进来能独立讲清楚的部分。本地还有一批扩展没有放进来，也没有写成文档——那部分是我们自己还在磨的东西，不想占作者的设计空间，作者那边要统一改就按自己的思路来。

补丁保持完整可编译：在 `2ee7b09` 干净树上 `git apply` 之后再 `tsc --noEmit`，退出码 0。这一版还排除了 `tests/bridge.live.ts`——它 import 的 `plugins/bridge` 不进版本库，留着只会让检查报“找不到模块”。

## 四、给别人用之前先读这段

**一、基线绑死。** 补丁对 `2ee7b09`。你那边版本不同就会冲突，`git apply` 直接失败。没有“自动适配”这回事。

**二、配置不在补丁里。** `config/` 在 `.gitignore`，里面的东西都不跟着走。装上等于半套：有些开关没有默认值，得自己照着代码补。

**三、改的是 `core/`。** 上游一更新就全废。这是补丁不是插件，没有别的办法。

**四、验证范围。** 所有补丁只在本人一台 Windows 电脑上跑过，没有跨机器验证。
