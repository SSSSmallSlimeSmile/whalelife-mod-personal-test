# 会话改名

## 现象

会话列表里每个会话显示的是首条消息截出来的片段，或者一个 id 前缀。开了十几个窗口之后，分不清哪个是“改补丁”、哪个是“查日志”。

## 触发原因

后端接口其实早就存在：

```
POST /api/memory/session/rename     参数 {id, name}
```

但**对话页没有任何入口**，只有直接调接口才能改。所以一直没人用。

我一开始判断“没有改名接口”，查过代码后才发现是自己漏看——接口在，缺的是界面。

## 触发场景

- 同时开多个会话，靠名字区分用途
- 长会话的首条消息跟主题已经没关系了
- 想给某次调试留一个可检索的名字

## 修法

1. `core/ui/views.js` 的「当前会话」按钮右边加一个铅笔图标
2. `core/ui/app.js` 加 `renameSession()`，`POST /api/memory/session/rename`，参数 `{id, name}`
3. 成功后顺手更新左侧列表里的显示名，不用整页刷新

## 复现步骤

1. 打开一个会话，点顶部「当前会话」旁的铅笔
2. 输入新名字，确认
3. 改前：找不到入口；改后：标题和左侧列表同时变成新名字，刷新后仍是新名字

## 验证

本机实际确认成功，刷新后名字保留。

## 应用注意

**只改显示名，不改 id 和文件路径。** 会话 id 决定 `memory/sessions/<id>/` 那套目录，改 id 等于搬目录，风险大得多，所以这里刻意没做。

作者那边如果给会话加了索引或缓存，记得让改名操作顺带失效一次。
