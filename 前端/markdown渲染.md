# 前端：Markdown 渲染

提交：`22e8296`（`core/ui/app.js` +177、`core/ui/styles.css` +118）

## 为什么做

聊天里发一个表格，页面显示的是竖线和短横线原样文字。

`renderRich` 原来只做两件事：把 `[[img:]]` 和 `[[voice:]]` 换成标签，其余内容一律 `escapeHTML` 转义，配合 `white-space: pre-wrap` 原样显示。

## 触发场景

任何包含可读排版的内容：

- 对比表（模型很爱用）
- 步骤列表
- 代码片段
- 标题分层

## 考虑过的方案

| 库 | stars | 为什么不用 |
|---|---|---|
| `markedjs/marked` | 37.3k | 吐原始 HTML，必须再配 DOMPurify（40KB），`core/ui` 多两个文件 |
| `markdown-it` | 22.0k | 更大，配置项多，同样要 sanitizer |
| `snarkdown` | 2.4k | 1KB 但**没有表格** |

**选了自己写**。理由：需要的不是完整 Markdown 解析器，是聊天里好看的排版。而且现在的做法"先全转义、再替换"，天然没有注入面。

## 做了什么

**块级**（`renderRich` 里，表格之后依次判断）

| 语法 | 结果 |
|---|---|
| `## ` ~ `###### ` | `<h3>` ~ `<h6>`（不出现 h1/h2，聊天里太大） |
| `---` 单独一行 | `<hr>` |
| `- / * / + ` | `<ul><li>`，支持两级嵌套 |
| `1. ` | `<ol><li>`，起始序号跟着写 |
| `> ` | `<blockquote>`，连续行合并 |
| ` ``` ` | `<pre><code>`，内部**不再解析行内语法** |
| 表格 | 表头 + `|---|` 分隔行判定，`:` 决定对齐 |

**行内**

| 语法 | 结果 |
|---|---|
| `**粗体**` | `<strong>` |
| `*斜体*` / `_斜体_` | `<em>` |
| `~~删除线~~` | `<del>` |
| `` `代码` `` | `<code>` |
| `[文字](url)` | `<a target=_blank rel=noopener noreferrer>` |

## 安全

**所有原始文本先 `escapeHTML`，再在这份已转义的字符串上做替换。** 没有允许原始 HTML 通过。

链接地址额外白名单：只放行 `http` / `https` / `mailto` 和相对路径，其他（`javascript:`、`data:`）一律降级成纯文本。

## 样式

照参考图做的：无外框、无竖线，只有底部细横线；表头灰色、字号 11.5px；右对齐列加 `tabular-nums`（金额能竖着对齐）；窄屏（≤720px）自动收小间距并允许横向滚动。

`<code>` 浅灰底、圆角、等宽；`<del>` 弱化色；`<strong>` 加粗、颜色用 `var(--ink)`。

## 应用注意

**纯静态文件，不用重启。** 改完 `Ctrl+Shift+R` 硬刷即可。

**已知短板**：不支持嵌套列表超过两级；不支持引用里的列表；不支持 HTML 表格。
